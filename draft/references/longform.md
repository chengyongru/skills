# Long-form technical writing

Let causal order determine structure. A useful default is:

1. concrete problem and consequence;
2. initial model;
3. evidence that changed it;
4. actual mechanism;
5. fix/experiment and result;
6. tested boundary;
7. reusable lesson.

Preserve exact numbers, commands, code, versions, links, traces, and failure modes. Distinguish measurement from interpretation and cite sources near supported claims.

Assume technical competence. Explain the missing causal step, use headings for navigation, and end at the strength supported by evidence. Let evidence determine length.

Return a working title, review-ready draft, and factual gaps that still need verification.

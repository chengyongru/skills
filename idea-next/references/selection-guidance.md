# Next-action selection

Choose the action that creates the most useful state change now: unknown -> known, blocked -> unblocked, draft -> reviewable, failing -> diagnosed, or private uncertainty -> external feedback.

For each serious candidate, form an internal thesis: action, decisive evidence, and expected state change. Compare:

1. readiness and clarity of the first probe;
2. size of the state change;
3. leverage across people, reviews, merges, or related ideas;
4. evidence quality;
5. delay cost;
6. fit with the user's current effort/context;
7. likelihood of producing signal.

Use cost/impact/confidence as hints rather than a score. Related links matter when they reveal a prerequisite, bottleneck, or cluster unlock.

Tie-break toward review-ready work, a clear diagnostic probe, closure of an open loop, a small cluster unlock, and current context. Under limited energy, favor an information-producing probe.

Return one action, the evidence-backed reason it wins now, and its first step. Include alternatives or rankings when requested.

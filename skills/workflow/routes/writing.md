# Writing

Choose the artifact and requested mode. Keep factual contracts, exact identifiers, locale, and legal notices intact while improving presentation.

| Work | Read next |
|---|---|
| Repository documentation, comments, docstrings, README, or contributor guidance | [Repository prose](../workflows/writing/prose/workflow.md) |
| A specifically requested writing-standard pass (`technical-writing`) | [Technical-writing method](../workflows/writing/prose/methods/technical-writing.md) |
| Remove AI-style filler or awkward prose (`unslop`) | [Style method](../workflows/writing/prose/methods/style.md) |
| Produce or update a PR title/body | [PR metadata](../workflows/pr/metadata/workflow.md) |
| Explain a mechanism rather than write a repository document | [Teach](../workflows/investigate/teach/workflow.md) |
| Restate the last reply plainly | [Plain language](../workflows/investigate/plain-language/workflow.md) |
| Product UI structure and interaction design | [UI design](../workflows/code/ui/workflow.md) |

Repository prose is the primary workflow. Read one of its methods when the requested edit needs it; do not run three overlapping editorial passes by default. Product interface strings follow the product's copy rules.

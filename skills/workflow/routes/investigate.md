# Investigate

Choose the question the user actually asked. Keep analysis read-only; follow-up implementation needs its own scope.

| Question | Workflow |
|---|---|
| What is this PR, issue, document, or unfamiliar topic, and what matters? | [Triage](../workflows/investigate/triage/workflow.md) |
| How does the subsystem run, and who owns the state? | [How](../workflows/investigate/how/workflow.md) |
| Why was this choice made, or why did behavior change? | [Why](../workflows/investigate/why/workflow.md) |
| Help me understand the mechanism and rationale together | [Teach](../workflows/investigate/teach/workflow.md) |
| Restate the goal before work (`in-your-own-words`) | [Understand](../workflows/investigate/understand/workflow.md) |
| Improve the task definition or approach (`sharpen`) | [Sharpen](../workflows/investigate/sharpen/workflow.md) |
| Reconstruct relevant prior work (`recall`) | [Recall](../workflows/investigate/recall/workflow.md) |
| Catch me up on this chat (`ketchup`) | [Catch up](../workflows/investigate/catch-up/workflow.md) |
| Restate the last reply without jargon (`bro`) | [Plain language](../workflows/investigate/plain-language/workflow.md) |
| Investigate an uncertain defect without fixing it yet | [Investigation](../playbooks/investigate/investigation.md) |
| Diagnose a running process or service | [Runtime forensics](../playbooks/investigate/runtime-forensics.md) |
| Explain a captured profile or trace | [Trace forensics](../playbooks/investigate/trace-forensics.md) |

Use bounded source/history reads. A source's summary is a claim, and a missing source remains a stated gap rather than a fabricated explanation.

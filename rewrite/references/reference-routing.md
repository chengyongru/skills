# Reference routing

Choose references by the decision they can improve:

| Reference | Reliable for | Boundary |
|---|---|---|
| current request | goal, tone, delivery | source facts |
| target source | facts, ownership, chronology, viewpoint | broader author style |
| author-approved before/after | selection, order, judgment strength, stopping point | new facts |
| author sample/profile | voice, rhythm, reader distance | current-topic opinion |
| factual source | names, numbers, mechanisms, limits | voice |
| platform sample | format, length, audience | facts and author viewpoint |

Priority: current request -> target source -> latest approved before/after -> closest author sample -> voice profile -> platform/general guidance.

Load two or three likely references from the current request, conversation-approved versions, bundled voice material, explicit reference directories, or named style guides. Use primary sources for unstable facts.

For each reference, identify its role, reliable decisions, 3-5 useful signals, and conflicts. Skip it when no concrete writing decision changes.

When comparing before/after, look for changed openings, deletions, reordered evidence, narrowed/strengthened judgments, ownership shifts, and where the author stopped. Transfer the decision rather than the wording.

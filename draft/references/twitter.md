# Twitter / X

Lead with one concrete fact; earn saves with a reusable result, resource, or method. Prioritize verified resources, engineering findings, and reusable agent workflows.

## Single post

Use short mobile-readable paragraphs:

```text
<specific audience, symptom, or number>
<what was tried>
<finding and evidence>
<transferable conclusion>
<optional link>
```

Keep canonical technical terms, the strongest before/after number, and material test conditions. Use hashtags, emoji, polls, or calls to action when the user requests them.

## Thread

Use a thread when one post would lose necessary evidence. Make the first post complete, use middle posts for investigation/evidence/caveats, and end with the reusable conclusion or checklist.

Replies address the actual point briefly. Quote posts add a concrete observation, correction, or tested result.

Return paste-ready copy first, followed by concise evidence gaps or alternate hooks when useful.

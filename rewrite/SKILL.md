# Rewrite

Improve the reading value of existing Chinese technical writing while keeping it recognizably the author's work.

## Evidence and ownership

- Treat the source as authority for facts, attribution, chronology, viewpoint, and uncertainty.
- Lock code, commands, parameters, paths, versions, numbers, outputs, links, and first-person experience unless the user authorizes a sourced factual change.
- Preserve strong original sentences and the author's casing, punctuation density, technical vocabulary, and distance from the reader.
- Distinguish event time, original writing time, and rewrite time; keep relative time words aligned with the final narrative position.

Read `references/reference-routing.md` when references are supplied or voice matching is requested. Read `references/chengyongru-voice.md` for the current user's voice when no newer, more specific approved sample exists. Use factual sources for facts, author samples for voice decisions, and platform samples for format.

## Edit depth

Use local edits when viewpoint and causal order already work: delete repetition, tighten weak passages, and repair unnatural sentences. Use structural edits when the current order hides the core judgment, causal change, evidence, or intended audience.

For short posts, optimize every sentence for mobile reading and keep the transferable conclusion ahead of links or calls to action.

## Workflow

1. Read the full source and identify its task, audience, ownership, chronology, strongest passages, and locked content.
2. Load only relevant references and state internally what each can influence.
3. Choose local or structural editing and focus on the one or two changes with the clearest net value.
4. Apply preserve -> delete -> move -> rewrite; add facts only with authorization and evidence.
5. Compare against the source, restore changes lacking clear benefit, and audit facts, ownership, chronology, voice, and locked content.
6. Return the rewritten text directly. Mention material uncertainty or sourced additions briefly.

Prefer deletion over replacement when a sentence only previews, repeats, over-explains, or adds generic polish. Stop once the evidence-backed point is clear.
